# Аудит Win11 Customizer — 2026-11-19

## Область проверки

Проверены Go-сервер, Win32-адаптеры, все HTTP-маршруты, транзакционный откат, установка обоев и тем, браузерный интерфейс, сборка Windows x64 и workflow релиза. Интерфейс и расположение существующих элементов сохранены; новые функции встроены в существующие карточки, поле выбора файла и панель резервной копии.

## Исправленные проблемы

- Команды `reg.exe` заменены глубоким модулем Win32 Registry: типы и сырые байты читаются через `RegQueryValueExW`, запись выполняется через `RegCreateKeyExW`/`RegSetValueExW`, ошибки больше не зависят от языка Windows.
- Перед мутацией создаётся точный снимок; составные операции и импорт профиля откатываются в обратном порядке, ошибки отката объединяются.
- Чтение состояния ускорено: для каждой карточки больше не запускается отдельный процесс.
- Добавлены HTTP timeouts, лимиты размера входных данных, allowlist системных страниц и проверка форматов тем.
- Добавлены проверка build Windows 11 и блокировка несовместимых настроек.
- Экспериментальные внутренние ключи Windows явно помечаются в интерфейсе.
- Профили проверяются до применения, конфликтующие операции отклоняются, импорт выполняется атомарно.
- Основные действия и ошибки записываются в `%ProgramData%\Win11Customizer\audit.jsonl`, журнал ротируется при достижении 5 МБ и доступен для скачивания. Журналирование работает по принципу best effort и не блокирует персонализацию при недоступном диске.

## Реализованное покрытие требований

- Темы Windows: импорт `.theme`, `.themepack`, `.deskthemepack`, возврат прежней темы через общий откат.
- Цвета, визуальные эффекты, панель задач, Пуск, курсоры, шрифты, звуки, заставка, экран блокировки и системные значки: безопасные переключатели либо переходы на официальные страницы Windows.
- Обычные и сетевые обои: установка с проверкой типа, размера, HTTPS-host и откатом.
- Автоматическая смена обоев: поддерживается в импортируемых пакетах тем/слайд-шоу средствами Windows.
- Проводник, приватность, игры и скрытые параметры: транзакционные переключатели с отметками риска и совместимости.
- Профили параметров: экспорт boolean-переключателей и темы интерфейса программы, подробный preview, предупреждения, импорт и автоматический rollback. Файлы обоев, шрифтов и курсоров внутрь JSON-профиля не встраиваются.
- Безопасность: приложение не патчит системные DLL, не заменяет Explorer и не загружает исполняемые скрипты из интернета.

## Сознательно исключено

Windows 11 не предоставляет штатного API для живых/видео-обоев. Полная реализация потребовала бы внедрения окна за значками рабочего стола, постоянного видеодвижка или сторонней программы. Это противоречит требованию не использовать сомнительные модификации, поэтому приложение принимает только изображения и штатные пакеты тем.

Недокументированное классическое контекстное меню также не возвращено: его популярный CLSID-трюк не имеет стабильного контракта Microsoft и может ломаться после обновлений.
