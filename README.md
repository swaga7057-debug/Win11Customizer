# Win11 Customizer

Портативная программа для безопасной персонализации Windows 11. Интерфейс работает локально через Edge или браузер по умолчанию; данные никуда не отправляются.

Версия 1.1 получила новый атмосферный интерфейс: глубокий синий фон, стеклянные панели, часы и нижний dock для навигации.

Версия 1.2 добавляет четыре темы интерфейса, установку собственных обоев JPEG/PNG/BMP и дополнительные параметры панели задач.

Версия 1.3 добавляет выдвижную панель быстрых настроек, тему Liquid Glass, расширенную кастомизацию панели задач и каталог интернет-обоев разных стилей.

## Скачать

Готовая сборка Windows x64 публикуется в разделе [Releases](https://github.com/swaga7057-debug/Win11Customizer/releases/latest).

## Возможности

- оформление, панель задач и Проводник;
- установка собственных обоев и готовых интернет-обоев прямо из приложения;
- темы «Океан», «Аврора», «Закат», «Полночь» и «Liquid Glass»;
- выдвижная панель быстрых настроек панели задач;
- управление поиском, виджетами, Copilot, значками, бейджами, акцентным цветом и панелью на нескольких мониторах;
- приватность и отключение рекламных рекомендаций;
- игровой режим и фоновая запись;
- системные параметры Windows 11;
- автоматическая резервная копия исходных значений реестра;
- общий откат, экспорт копии и создание точки восстановления;
- разделение безопасных и требующих внимания настроек.

## Запуск

Откройте `Win11Customizer.exe`. Для параметров с отметкой **ADMIN** запустите файл через «Запуск от имени администратора». Остальные параметры работают без повышения прав.

Резервная копия хранится в `%ProgramData%\Win11Customizer\backup.json`.

## Сборка

```powershell
$env:GOOS = "windows"
$env:GOARCH = "amd64"
go build -trimpath -ldflags="-s -w -H=windowsgui" -o Win11Customizer.exe .
```

Проект использует только стандартную библиотеку Go и не требует внешних зависимостей.
